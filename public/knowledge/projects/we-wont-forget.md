# We Won't Forget — Digital Memorial & Archival Platform

## 1. Overview
- **Project Name:** We Won't Forget
- **Live Deployment:** https://wewontforget.in
- **Case Study Route:** /projects/we-wont-forget
- **Role:** Lead Full-Stack Engineer & Interaction Designer
- **Type:** Archival Platform & Digital Memorial
- **Target Audience:** Historical societies, families, and community members preserving historical memories and commemorative tributes.

## 2. The Problem
Online community memorial and archival archives frequently suffer from performance degradation:
- Bloated visual assets leading to slow page loads and layout shifts (CLS) on mobile devices.
- Unstructured narrative flows making chronological timeline navigation confusing for visitors.
- Lack of spam-protected yet friction-free tribute submission channels.

## 3. The Solution
We Won't Forget was built with a performance-first and dignified aesthetic philosophy:
- Next.js Static Site Generation (SSG) with Incremental Static Regeneration (ISR) guaranteeing instant edge delivery.
- Interactive chronological timeline featuring responsive fluid typography and high-contrast accessibility.
- Zero-layout-shift image delivery with pre-computed aspect ratios and modern WebP format conversion.
- Moderated community tribute submission workflow backed by headless CMS integration.

## 4. Architecture & Engineering Implementation
- **Frontend Framework:** Next.js with React 18, TypeScript, and CSS Modules.
- **Content Management:** Sanity CMS headless studio for archival storytelling and tribute curation.
- **Media Optimization:** Next.js Image optimization pipeline serving responsive WebP assets.
- **Hosting & Edge Delivery:** Vercel Global Edge Network.

## 5. Key Results & Metrics
- **Lighthouse Performance Score:** 100/100 across Performance, Accessibility, and Best Practices.
- **Initial Page Load:** <0.4 seconds over typical mobile connections.
- **Community Engagement:** 5,000+ verified tributes recorded.
- **Bounce Rate:** <18%, indicating prolonged user engagement with the historical archives.
